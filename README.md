# Career Quest

Внутренняя HR-платформа для объяснимых рекомендаций по развитию сотрудников.
Сотрудник видит профиль, разрывы навыков до следующего грейда и до трёх
активностей. HR-view агрегирует проседающие компетенции без публичного рейтинга.

## Архитектура и технологии

- FastAPI, Uvicorn, Pydantic v2 и Python 3.12;
- детерминированный скоринг в `BackendAI/app/services/scoring.py`;
- OpenAI и NVIDIA используются только для формулировки объяснений;
- при отсутствии ключей или ошибке LLM работает локальный fallback;
- JSON/CSV из `BackendAI/dataset/` загружаются в память без базы данных;
- FastAPI раздаёт интерфейс из `static/`;
- frontend использует vanilla JS, Tailwind CDN и реальные API `/api/*`.

Исходные файлы dataset не изменяются. Uploads и симулированные завершения
активностей хранятся в памяти и сбрасываются после перезапуска.

## Запуск через Docker Compose

Требуются Docker с Compose v2 и свободный порт `8000`.

```bash
docker compose up --build
```

Приложение доступно на <http://localhost:8000>, документация API — на
<http://localhost:8000/docs>, health check — на
<http://localhost:8000/api/health>.

```bash
# Логи
docker compose logs -f app

# Остановка
docker compose down
```

Приложение работает без внешних аккаунтов и LLM-ключей. Для live-объяснений
скопируйте пример и заполните один или оба ключа:

```bash
cp .env.example .env
```

Файл `.env` необязателен для запуска и исключён из Git.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `HOST`, `PORT` | Адрес и порт Uvicorn; по умолчанию `0.0.0.0:8000` |
| `OPENAI_API_KEY`, `NVIDIA_API_KEY` | Необязательные ключи LLM-провайдеров |
| `OPENAI_MODEL`, `NVIDIA_MODEL` | Используемые модели провайдеров |
| `LLM_TIMEOUT_SECONDS` | Таймаут LLM-провайдера |
| `DATA_DIR` | Каталог исходного dataset внутри backend |
| `SNAPSHOT_DATE` | Дата расчёта стажа, истории и доступности сессий |
| `MAX_UPLOAD_BYTES` | Максимальный общий размер upload batch |
| `CORS_ORIGINS` | Разрешённые origins через запятую или JSON-массивом |

## Алгоритм рекомендаций

Скоринг выполняется только Python-кодом и учитывает:

1. разрыв между текущим и требуемым уровнем навыка;
2. критичность навыка для следующего грейда;
3. историю похожих активностей, включая пропуски и отказы;
4. достижимый прирост с учётом `gain` и `max_level`.

Базовые компоненты: `10 × gap`, `10 × min(gain, gap)`, бонус `20` за
критичный навык и штраф `30` за негативную похожую попытку. При равном
результате используется стабильная сортировка по `event_id`. Ответ API содержит
числовой объект `factors`; LLM не влияет на выбор, баллы или порядок.

Подробности контрактов и загрузки данных описаны в
[`BackendAI/README.md`](BackendAI/README.md).

## Проверка основного сценария

Откройте интерфейс, выберите сотрудника, просмотрите профиль и рекомендации,
отметьте активность выполненной, затем проверьте обновлённый прогресс и HR-view.
Во вкладке «Данные» можно загрузить проверочные JSON/CSV и выполнить reset.

```bash
curl --fail http://localhost:8000/api/health
curl --fail http://localhost:8000/api/employees?limit=1000
curl --fail -X POST http://localhost:8000/api/recommend \
  -H 'Content-Type: application/json' \
  -d '{"employee_id":"E0001"}'
```

Тесты backend не требуют внешних API:

```bash
python -m pytest BackendAI/tests -q
```

## Известные ограничения

- используется один worker, поскольку состояние хранится в памяти;
- restart/reset удаляет uploads и симулированный прогресс;
- переключатель роли в UI не заменяет серверную авторизацию;
- зависимости ограничены диапазонами версий, lock-файл отсутствует;
- успешный внешний LLM улучшает только текст объяснения, не рекомендацию.

## Использованные внешние материалы

- FastAPI, Uvicorn, Pydantic, Pandas и OpenAI Python SDK;
- Tailwind CSS и Google Fonts загружаются интерфейсом через CDN;
- исходный hackathon dataset и требования находятся в `BackendAI/dataset/` и
