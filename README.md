# Career Quest

## Описание и назначение

Внутренняя платформа для просмотра профиля сотрудника, разрывов по навыкам до следующего грейда и объяснимых рекомендаций по активностям. HR-экран показывает агрегированные данные.

## Архитектура

FastAPI в `BackendAI/app/` отдаёт API и файлы из `static/`. Исходные данные лежат в `BackendAI/dataset/`. Рекомендации ранжируются локально; LLM формулирует объяснения при наличии API-ключа. Без ключа используются локальные объяснения.

## Технологии

Python 3.12, FastAPI, Uvicorn, Pydantic v2; HTML, Tailwind через CDN, vanilla JavaScript.

## Требования

Для запуска в контейнере нужен Docker с Compose. Для локального запуска и тестов нужен Python 3.12+.

## Установка

Для контейнера установка зависимостей выполняется при сборке образа. Для локального запуска: `python -m pip install -r BackendAI/requirements.txt`.

## Переменные окружения

Создайте `.env` в корне проекта при запуске через Compose. Список переменных и примеры значений есть в `BackendAI/.env.example`. Без `.env` приложение запускается с локальными объяснениями.

| Переменная | Назначение |
| --- | --- |
| `OPENAI_API_KEY` | Ключ OpenAI для объяснений рекомендаций, опционально |
| `OPENAI_MODEL` | Модель OpenAI, по умолчанию `gpt-4o-mini` |
| `NVIDIA_API_KEY` | Резервный провайдер объяснений, опционально |
| `DATA_DIR` | Каталог данных; относительный путь считается от `BackendAI/` |
| `HOST`, `PORT` | Адрес и порт сервера; по умолчанию `0.0.0.0:8000` |

## Запуск

Из корня проекта: `docker compose up --build`. Интерфейс: `http://localhost:8000/`; API: `/api`; документация API: `/docs`.

Локально: `python BackendAI/run.py`. Пути к статике и данным не зависят от текущей директории.

## Проверка основного сценария

Откройте интерфейс, выберите сотрудника, просмотрите профиль и рекомендации, отметьте активность выполненной, затем откройте HR-экран. Загрузку данных можно проверить в разделе «Данные»; формат файлов описан в `BackendAI/README.md`.

## Проверка без аккаунтов команды

Интерфейс и локальные объяснения работают без внешнего аккаунта. Запустите `python -m pytest BackendAI/tests -q` и откройте страницу без API-ключей.

## Известные ограничения

Данные и изменения хранятся в памяти процесса; перезапуск возвращает исходный датасет. Роль в интерфейсе не заменяет серверную авторизацию. Без настроенного ключа `llm_used` равен `false`.

## Использованные внешние материалы

Tailwind CDN и Google Fonts загружаются браузером; зависимости Python перечислены в `BackendAI/requirements.txt`.
