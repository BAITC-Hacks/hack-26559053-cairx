# Правила проекта для AI-агента

## Назначение

Разрабатывай сервис умного подбора event-подрядчиков на основе `hackathon-dataset-anonymized.jsonl` (66 профилей). Вход: город, дата мероприятия, тип мероприятия, категория подрядчика, бюджет в тенге; длительность и язык — необязательные поля. Выход: до трёх карточек подрядчиков с конкретным объяснением, почему каждый подходит под запрос.

## Стек и структура

- Backend: Python 3.12, FastAPI, Uvicorn, Pydantic v2.
- Frontend: один `static/index.html` с Tailwind и DaisyUI через CDN и vanilla JavaScript. Его отдаёт тот же FastAPI.
- Запуск проекта: `docker compose up`.
- LLM: OpenAI API. Ключ считывай только из переменной окружения.
- Размещай роуты в `app/main.py`, схемы в `app/schemas.py`, фильтрацию, ранжирование и объяснения в `app/services/`, интерфейс в `static/index.html`.
- Не добавляй React, Vue, npm или сборщики.

## Логика и надёжность

- Используй реальные профили из датасета и реальную логику подбора. Не подменяй их моками, заглушками или захардкоженными ответами.
- Валидируй входные данные через Pydantic. Добавь глобальный обработчик ошибок, возвращающий понятный JSON.
- Обеспечь детерминизм: одинаковый запрос должен давать одинаковый порядок карточек. Применяй стабильную сортировку с явным разрешением равенства оценок; при обращении к LLM устанавливай `temperature=0`.
- Если LLM недоступен, формируй объяснения запасным путём без него. Подбор подрядчиков должен продолжать работать.
- Храни секреты только в переменных окружения. Не коммить `.env`.
